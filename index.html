ODS 6 — Água Potável e Saneamento

O projeto Água na Conta busca utilizar tecnologia para estimular o uso consciente da água e tornar mais visível a relação entre hábitos, consumo e economia.

🎯 Objetivo

Criar uma ferramenta acessível que ajude as pessoas a compreenderem seus hábitos de consumo e acompanharem possíveis reduções ao longo do tempo.

  • ✓ Estimativa educativa de consumo
  • ✓ Comparação de contas
  • ✓ Acompanhamento de economia
  • ✓ Desafio de mudança de hábitos
  • ✓ Visualização de impacto

💡 Tecnologia

Esta versão utiliza tecnologias web simples, leves e acessíveis.

  • ✓ HTML5
  • ✓ CSS3
  • ✓ JavaScript
  • ✓ LocalStorage
  • ✓ Design responsivo

🔐 Privacidade

A primeira versão não exige cadastro nem login. Os dados utilizados pela plataforma são armazenados localmente no navegador.

Isso reduz a barreira de entrada e facilita a utilização da plataforma em atividades de extensão.
